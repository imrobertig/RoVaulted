# RoVaulted

**A local-first developer workspace with practical tools for everyday projects.**

## Features
- Save, tag, search, edit, and copy code snippets.
- Generate Markdown changelogs from release notes.
- Format, minify, and validate JSON.
- Inspect image dimensions, aspect ratio, file type, and file size.
- Create, prioritize, complete, filter, and delete project tasks.
- Dashboard with recent activity and quick access.
- Local browser storage; no login, backend, or external dependencies.

## Run locally
Open `index.html` in a modern browser. No build step required.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `app.js`, `README.md`, and `LICENSE` to the root of a GitHub repository. Go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Privacy and limitations
Snippets, tasks, and activity are stored in browser `localStorage` on the current device/browser. This is not cloud sync. Clearing browser storage may erase saved data. The asset checker reports image properties only and does not validate platform-specific requirements.
